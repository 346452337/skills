# 超强微信公众号文章下载器

> 纯本地部署 · 无需API KEY · 自动绕过验证码

## 一键下载

```bash
# 自动触发：发送任意微信公众号链接即可
https://mp.weixin.qq.com/s/xxxxx
```

## 核心特性

| 特性 | 说明 |
|------|------|
| 零依赖 | 无需任何外部 API KEY，纯本地运行 |
| 双模式 | curl(快速) → CloakBrowser(隐身浏览器) 自动切换 |
| 防封禁 | 智能绕过微信验证码与反爬机制 |
| 自进化 | 连续失败自动分析并更新策略 |
| Markdown | 自动生成带 YAML 元数据的 Markdown 文件 |
| 图片下载 | 自动下载文章内嵌图片到本地 |
| Git 同步 | 自动提交并推送到远程仓库 |

## 输出示例

```markdown
---
title: "文章标题"
author: "公众号名"
date: "2026-05-12"
source_url: "https://mp.weixin.qq.com/s/xxxx"
download_mode: "curl"
---

# 文章标题

文章正文内容...

![](imgs/img-001.png)
```

## 目录结构

```
~/wechat/raw/
├── 文章标题.md           # Markdown 文件
├── 文章标题/             # 图片目录
│   └── imgs/
│       ├── img-001.png
│       └── img-002.png
```

## 快速开始

1. 确保 CloakBrowser 已安装在 `/root/.cloakbrowser/`
2. 发送微信文章链接，自动下载
3. 输出目录：`~/wechat/raw/`

## 工作原理

```
┌─────────────────┐
│  微信文章 URL   │
└────────┬────────┘
         ▼
┌─────────────────┐    成功    ┌─────────────┐
│   curl 模式      │ ─────────► │ 保存 + Push │
└────────┬────────┘             └─────────────┘
         │ 被拦截
         ▼
┌─────────────────┐    成功    ┌─────────────┐
│ CloakBrowser    │ ─────────► │ 保存 + Push │
│ 隐身浏览器模式   │            └─────────────┘
└────────┬────────┘
         │ 仍被拦截
         ▼
┌─────────────────┐
│   自进化修复    │ → 更新策略 → 重试
└─────────────────┘
```

## 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `OUTPUT_DIR` | `~/wechat/raw` | 输出目录 |
| `WECHAT_TIMEOUT` | `90000` | CloakBrowser 超时(ms) |

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| curl 被拦截 | 自动切换 CloakBrowser |
| 图片下载失败 | 自动携带 Referer 头 |
| Git 推送失败 | 检查远程仓库权限 |
| 部分文章无法获取 | 自进化模式更新策略 |
